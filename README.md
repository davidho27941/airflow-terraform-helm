# airflow-terraform-helm

Customized Airflow Helm chart deployment with Terraform configuration.

CAUTION: Current README content is generated by Cursor.

## Overview

This project provides a solution for managing and deploying Apache Airflow using Terraform and Helm Chart. It implements Infrastructure as Code (IaC) principles for automated deployment and management of Airflow environments.

## Prerequisites

- Kubernetes cluster
- Helm
- Terraform
- kubectl configured with cluster access

## Quick Start

1. Initialize Terraform:

```
terraform init 
```

2. Review the deployment plan:

```
terraform plan
```

3. Apply the configurations:

```
terraform apply
```

## Configuration

This project includes configurations for:

- Basic Configurations
- Webserver and Ingress 
- Volume and Volume Mount 
- Environmental Variables

For detailed configuration parameters, please refer to the `variables.tf` file.
