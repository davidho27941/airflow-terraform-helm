# airflow-terraform-helm

Customized Airflow Helm chart deployment with Terraform configuration.

CAUTION: Current README content is generated by Cursor.

## Overview

This project provides an Infrastructure as Code (IaC) approach to deploying and managing Apache Airflow environments using Terraform and Helm. It offers a customizable, maintainable, and automated way to set up Airflow on Kubernetes clusters.

## Features

- 🚀 Automated Airflow deployment on Kubernetes
- ⚙️ Highly customizable configuration via Terraform variables
- 📦 Helm chart management for Airflow components
- 🔒 Secure secrets management
- 🔄 Scalable and maintainable infrastructure setup
- 🌐 Configurable ingress settings
- 💾 Persistent volume management

## Prerequisites

Before you begin, ensure you have the following tools installed:

- Kubernetes cluster (1.20+)
- Helm (3.0+)
- Terraform (1.0+)
- kubectl configured with cluster access

## Quick Start

1. Clone the repository:
```bash
git clone https://github.com/yourusername/airflow-terraform-helm.git
cd airflow-terraform-helm
```

2. Initialize Terraform:
```bash
terraform init
```

3. Review the deployment plan:
```bash
terraform plan
```

4. Apply the configuration:
```bash
terraform apply
```

## Configuration

### Basic Configuration

The deployment can be customized through variables in `variables.tf`. Key configuration areas include:

- Airflow version and components
- Webserver and Ingress related settings
- Volume, Volume Mount and GitSync Secrets
- Environment variables for airflow-only and deployment-wise configurations

### Advanced Configuration

For advanced customization, you can modify:

- Webserver and Ingress settings
- Volume and Volume Mount configurations
- Environment variables
- DAG deployment settings
- Security configurations

## Accessing Airflow

After successful deployment, you can access the Airflow web interface through:

1. Port forwarding:
```bash
kubectl port-forward svc/airflow-webserver 8080:8080 -n airflow
```

2. Or through the configured Ingress (if enabled)
